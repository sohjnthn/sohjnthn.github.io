Early Mesos Farming

Focus on grinding mobs in suitable MapleStorySEA training maps and sell valuable drops using Maple Auction. These include: 1) Selling every 9,000 extra Spell Traces (please keep enough for your characters' use). 2) Learn at least lv6 Alchemy (requires learning lv1 Herbalism via Ardentmill) for at least the main character to be able to disassemble equipment for all character levels; in order to disassemble the expedition boss equipment which can only be sold for 1 Meso to an NPC shop. 3) For all characters, carry out the about lv125+ Korean Folk Town - Warning Sign/Wanted Poster mobbing quests for a lot of Mesos; and some EXP. Important: It is only safe for characters to carry out the 5th job advancment, if their clean damage ranges are from 0.6m to 1.0m (the lower to the higher numbers, for the Stat ATT as compared to the Combat Power), therefore these characters should only train the Hyper Stat Damage+% to lv10 before carrying out the 5th job advancement, to prevent paying 10m Mesos for resetting the Hyper Stats.

Efficient Gear Progression

Rely on boss drops, events, and progression gear. Enhance equipment using Mesos only. As advised by other players, only for the main character (due to the high Mesos costs for enhancing the Arcane; and Authentic Symbols), via the Maple Auction, purchase the following clean (non-spell trace/star force/normal potential/additional potential-enhanced; but can have additional stats in blue text); and cheapest equipment: 1) lv200 Archaneshade hat, shoes, gloves, cape, and shoulder decoration 2) lv150 Root Abyss top, and bottom Then, slowly enhance these equipment (which are untradable once equipped) with the following event items: 1) The scrolls which have a 100% chance of providing 20 or less stars to untradable equipment 2) Karma Rainbow Resurrection Flames 3) Karma Choice Cubes (for normal potential) 4) Karma Choice Additional Cubes In case of any remanining tradable equipment, please kindly use the Daily Gift's Choice Cubes; and Choice Additional Cubes.

Daily Bossing

Defeat the daily expedition boss monsters for steady Mesos income; and useful drops without using Cash Shop. Only the first character who defeats a particular expedition boss monster for the same day, can manually receive the related Boss Mileage. By the time the main character reaches lv11 for the Authentic Symbol: Arcs (for the 6th job advancement - Hotel Arcs region), the lv9 Hexa skill for the 4th job main attack skill (for some jobs, the strongest main attack skill without cooldown duration, can be the 3rd job - for example, for Ho Young); or the 2nd job main attack skill - for example, for Mo Xuan), can be used for 1 to 3 times to defeat each part of the following expedtion boss monsters: 1) Normal Arkarium: About 3 times 2) Normal Papulatus: About 2 times for each part, for the two parts 3) Normal Magnus: About 2 times, but remember to teleport/jump backwards to avoid the forward sword rush attack which does about 25%; or more buffed HP damage to the player character. 4) Hard Von Leon: About 1 time; Hard Von Leon drops the lv130 Von Leon equipment, instead of the coins for the related coin shop. 5) Normal Pink Bean: Use the first released 6th job attack skill (not the second released 6th job attack skill which is the Ascent skill) first; followed by using the lv9 Hexa skill for the 4th job main attack skill for about 1 time. Do not only measure the clean damage ranges of your characters only with the Combat Power; but as the average of the Combat Power, and the Stat ATT. This Stat ATT is the same as the Stat ATT - Basic (Only Stat ATT increases if a passive skill, such as the Explorer Magicians' (Bishop, Arch Mage (Fire, Poison), and Arch Mage (Ice, Lightning) 4th job Infinity skill, increases Final Damage+% passively). Also noting that the Explorer Magicians' job-specific V Core skill Precarious Memories, has been changed to Arcana Overdrive, which temporarily increases Final Damage+%.
